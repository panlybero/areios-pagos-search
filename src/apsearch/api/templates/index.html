🤖 Σύνδεση με AI Agent (MCP)

Ο ενσωματωμένος Model Context Protocol (MCP) server επιτρέπει σε εφαρμογές όπως το OpenWork, το Claude Desktop ή το Cursor να αναζητούν αποφάσεις απευθείας.

Ρύθμιση για OpenWork / Claude (HTTP): 
{
  "mcpServers": {
    "areios-pagos": {
      "httpUrl": "http://localhost:8766/mcp"
    }
  }
}

Επικολλήστε το παραπάνω τμήμα στο αρχείο ρυθμίσεων του agent σας (π.χ. στο OpenWork Settings → MCP Servers ή στο claude_desktop_config.json).

⏳ Υπολογιστής Κόστους & Ανάκτηση Ετών

Μπορείτε να ανακτήσετε παλαιότερα έτη (1994–2017) απευθείας στη συσκευή σας. Η εφαρμογή υπολογίζει εκ των προτέρων το εκτιμώμενο κόστος του Gemini API:

Εκτιμώμενες Αποφάσεις: ~16,000
Εκτιμώμενα Αποσπάσματα (Chunks): ~350,000
Εκτιμώμενος Χρόνος (0.5 req/s): ~10 ώρες
Εκτιμώμενο Κόστος API: ~$22 - $26
⚠️ Η ανάκτηση γίνεται με σεβασμό στον διακομιστή του Αρείου Πάγου και μπορεί να διακοπεί και να συνεχιστεί οποιαδήποτε στιγμή. Το κόστος χρεώνεται απευθείας στον προσωπικό σας λογαριασμό Google AI Studio.
